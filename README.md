# Smart Energy Meter Interface with GSM and VLSI Logic Processing

An advanced embedded systems portfolio piece implementing an automated digital utility infrastructure metering configuration. The project features a discrete mix of high-speed hardware signal calculation elements and external telecommunications array subsystems.

## System Block Diagram Matrix
- **Analog Sensor Inputs** -> Current/Voltage Transformer ADC Stepdown Rails.
- **VLSI DSP Processing Core (`VHDL`)** -> Executes hardware active multiplication logic mapping instantaneous power metrics and integrates totalized energy consumption value metrics directly inside data registers.
- **Microcontroller Subsystem (`C Logic`)** -> Reads memory-mapped hardware values from calculation units and translates raw logs into actionable billing summaries.
- **GSM Telecommunications Node (`AT Interfacing`)** -> Drives serial lines to prompt cell network text messaging delivery blocks carrying real-time cost updates to structural database systems.

## Key Features & Highlights
- **Synthesizable VHDL Math Elements:** Pure combinational processing matrix preventing firmware clock cycle bottleneck latency.
- **Automated Communication Protocol Sequences:** Robust C parsing framework automating AT setup vectors (`AT+CMGF=1`, `AT+CMGS`) along with frame termination blocks (`Ctrl+Z`).
- **Billing System Integration Simulation:** Local parameters dynamically translate monitored hardware consumption measurements into real-time account balances owed.
